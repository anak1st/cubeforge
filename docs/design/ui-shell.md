# UI 壳:开始屏幕 / 暂停画面

状态:已实现,待人工验收(2026-09-02)。

## 为什么先做壳

可玩切片(已回退)的病灶是**状态双源**:状态真值在 game 层闭包里,React 靠回调镜像一份,
指针锁失败还会"乐观进入再修正"。这次反转次序——先把 UI 壳(应用状态机 + 两个画面)做对,
世界代码之后从壳里长出来,`SceneCanvas` 内部换成真游戏场景时壳不动。

## 应用状态机

单一事实源:`src/ui/store.ts`(zustand)。应用状态是 **UI 画面**的定义,不是 game 内部状态;
将来 game 层只消费应用状态、上报输入事件,自己不存。

```
menu ──开始游戏──▶ playing ──ESC(浏览器退锁)──▶ paused
 ▲                                            │ 继续(点击重锁)
 └────────────── 返回菜单 ────────────────────┘
```

画面与应用状态的对应(互斥关系是硬边界):

- `menu`:独立开始屏幕,**不挂载游戏画布**(对齐 MC 标题屏与游戏画面分离;"返回菜单"= 销毁游戏画面)
- `playing`:游戏画布运行
- `paused`:游戏画布保留但冻结,暂停菜单作覆盖层

三个动作(start / pause / backToMenu)是直接 setter,不做合法性守卫:
按钮只出现在正确的状态里,非法迁移无处触发。"playing 必须先暂停才能回菜单"
由 UI 流程保证——暂停菜单是"返回菜单"的唯一入口。

## 指针锁协议(状态迁移的唯一输入源)

- **开始游戏**:StartMenu 只切应用状态,不碰锁。游戏画布在挂载 effect 里
  `requestPointerLock()`(仍在点击的激活窗口内),拒绝则 `pause()` 落到暂停菜单——可见、可重试。
- **获得锁**(`pointerlockchange` → 有锁元素):`start()`。暂停菜单"继续"走这条路径,
  成功路径完全由 change 事件驱动,无双源。
- **丢失锁**(playing 中按 ESC / 切页签被浏览器退锁):`pause()`,画面冻结。
  将来"清移动键防卡键"也挂在这里。
- **恢复只能点击**:ESC 退锁后的一段时间内,Pointer Lock 规范**强制拒绝**一切重锁请求
  (Chrome 约 1.25s),Escape 键也不是可靠的激活来源;标准做法即只从点击重锁。
  ESC 恢复不可行是与桌面 MC 的差异,属浏览器约束而非实现取舍。
- **冷却可见**:暂停菜单出现后"继续"禁用 1.25s,结束自动恢复并聚焦;
  promise catch 兜底其余拒绝(如权限),显示"请稍候再试"。

## 组件结构

```
src/ui/
  App.tsx        壳:menu 渲染开始屏幕,否则渲染游戏画布(+暂停覆盖层);挂 pointerlockchange
  store.ts       zustand 应用状态机
  pointer-lock.ts 锁目标注册 + 请求封装(promise 化,拒绝可感知)
  StartMenu.tsx  独立开始屏幕:标题 + 开始游戏(只切状态,不碰锁)
  PauseMenu.tsx  暂停覆盖层:继续(重锁冷却结束前禁用)/ 返回菜单
  MenuButton.tsx 像素风统一按钮(M7 全面像素化前的过渡样式,纯 CSS)
  SceneCanvas.tsx 仅 playing/paused 挂载;挂载即抓锁;setRunning(appState === 'playing')
```

分层合规:ui 不 import three;scene 的 `setRunning` 是 render 层 API。

## 运行条件

游戏画面允许运行的状态**只有 playing**:`menu` 根本没有画布,`paused` 冻结自转但渲染
不中断(对齐 MC 暂停时世界冻结、画面仍刷新)。自转用增量累进(dt 截断),冻结恢复不跳变。
M7 接入设置/存档时再扩展应用状态(如 settings 态)。

## 验收清单(浏览器,Chrome)

1. `pnpm dev` → 开始屏幕:黑底 + 标题 + 开始游戏,**无任何游戏画面**
2. 点开始游戏 → 游戏画面出现(方块自转)、指针锁定
3. 按 ESC → 暂停覆盖层浮现(变暗模糊),**方块冻结**;"继续"呈禁用态
4. 暂停中按 ESC → 无反应(恢复只能点击,浏览器约束)
5. 约 1.25s 后"继续"自动恢复可点并聚焦,点击后方块恢复转动且无角度跳变
6. 返回菜单 → 游戏画面消失,回到开始屏幕
7. Tab/Enter 可操作按钮,按钮有焦点框
