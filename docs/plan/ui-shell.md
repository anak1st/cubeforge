# UI 壳:开始屏幕 / 暂停画面

状态:已实现,待人工验收(2026-09-02)。

## 应用状态机

单一事实源 `src/ui/store.ts`(zustand),应用状态 = UI 画面的定义:

```
menu ──开始游戏──▶ playing ──ESC(浏览器退锁)──▶ paused
 ▲                                            │ 继续(点击重锁)
 └────────────── 返回菜单 ────────────────────┘
```

- `menu`:独立开始屏幕,不挂载游戏画布;`playing`:画布运行;`paused`:画布冻结 + 覆盖层
- 三个动作是直接 setter,不做守卫——按钮只出现在正确的状态里

## 指针锁协议

- 开始游戏只切状态;画布挂载时请求指针锁(点击激活窗口内),拒绝 → paused 重试
- 恢复只能点击:Pointer Lock 规范在 ESC 退锁后约 1.25s 强制拒绝重锁(防锁死陷阱),Escape 键也非可靠激活来源
- 冷却以"继续"按钮禁用 1.25s 表达,结束自动恢复并聚焦

## 验收清单(Chrome)

1. 开始屏幕无任何游戏画面;点开始 → 草方块双轴自转、指针锁定
2. ESC → 暂停覆盖层(变暗模糊),方块冻结,"继续"禁用约 1.25s 后自动可点并聚焦,点击后恢复无角度跳变
3. 暂停中按 ESC 无反应(恢复只能点击);返回菜单 → 画布消失回开始屏幕
4. Tab/Enter 可操作按钮,按钮有焦点框
